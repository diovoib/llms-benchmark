Local agent benchmark · tools · agent

Eight local models in a tool-using agent test

For day-to-day use on this machine: Gemma 4 12B — 96 percent hard-pass, median under a second. Gemma 26B wins the headline score only because it is the one that still asks before deleting a file. Qwen 9B is the fastest; the 27B is too slow for chat; Granite breaks Polish city names; GLM falls apart at temperature 0.7.

Glossary used in this report

Names in monospace are configuration keys: profiles, suites and prompt_variants.

  • Turn — one replay of one case: from sending the query to the model until its reply finishes. Turn time is wall-clock time for that operation, not a token sum.
  • tools — suite: a single reply with a function call. 31 cases. Repeats: 2 in greedy, 5 in real.
  • agent — suite: a multi-step loop (call, read the result, next decision). 13 cases. Repeats: 2 in greedy, 3 in real.
  • greedy — profile: temperature 0, fixed RNG seed. Repeatability check.
  • real — profile: temperature 0.7, varying seed. Closer to day-to-day use.
  • neutral — prompt_variant: no system prompt.
  • helpful — prompt_variant: the single sentence “You are a helpful assistant.”
  • instructed — prompt_variant: a long instruction: call tools natively, do not invent arguments, do not alter values returned by a tool, ask when the request is ambiguous.
  • Hard pass — a mechanical condition: a correct native tool call, or correctly refraining from a call. Fluent prose with no call, when a call was required, does not pass.
  • “Day-to-day” ranking — mean hard-pass rate in real, only neutral and helpful. It drops instructed, which lowers the score in this measurement.

Verdict

For a day-to-day local tool-using agent on this machine, the pick is Gemma 4 12B Q5_K_M. In real, without instructed, it gets a 96 percent hard-pass rate; with neutral almost 99 percent. Median reply time falls below one second. Gemma 4 26B wins the headline score only because it is the only one that still asks for confirmation before deleting a file when the system instruction both requires tool calls and requires asking on a conflict.

Qwen 3.5 9B is the fastest and the only model that, in both languages, composes an event and an email in one turn, in the right order, with the right attendees. It is a poor fit where the server sometimes disables tools: in 100 percent of those turns it pastes a call marker into the text instead of a plain reply.

Qwen 3.8 27B has similar substance and is too slow to use interactively: 25 s per turn on average, 36 generations cut by the 60 s limit. Granite 4.2 8B can be solid in English; in Polish it pastes the locative Wrocławiu into the tool instead of the nominative city name, and never composes two tools in one turn. Ornith sits in the middle of the field. LFM 2.5 with the prompt “You are a helpful assistant” refuses to use tools it was given in the catalog. GLM 4.7 Flash looks mid-pack at temperature 0, and at 0.7 it breaks arguments: it pastes comments, Warsaw, Poznań and locale codes into the city field.

instructed does not fix models — it lowers the score by 11–28 percentage points. Two mechanisms: (1) the Polish decimal comma 14,3 instead of the literal 14.3 from the tool result, (2) the instruction “use a tool when the task needs it” beats the policy “do not delete without confirmation”. This is a result about day-to-day frustration, not a broken test.

How to read these numbers

A hard pass means: a native tool call in the server format, the right tool, arguments that match the schema and what the user actually said, and — in agent — quoting the tool result or refraining from action. Fluent, “helpful” prose with no call, when a call was required, is a fail. The point of the measurement: whether the model will be frustrating as an agent engine, not whether it sounds polite.

The greedy profile (temperature 0, fixed seed) is a repeatability control. The real profile (temperature 0.7) is closer to production. The gap between them is 1–3 percentage points for most models, so the ranking is not an artefact of zeroing temperature alone. Exception: GLM 4.7 Flash loses 34.7 percentage points going from greedy to real.

Models: strengths, weaknesses, recommendation

Gemma 4 12B IT Q5_K_M — recommendation for day-to-day work

Headline score 88.3 percent, “Day-to-day” ranking 96.4 percent. tools 97.7 percent (636 of 651 turns), the best tools score in the field. greedy × neutral: 100 percent. It respects the server disabling tools (T08), does not guess a city (T04), does not substitute a colour off the list (T12), copies an identifier with special characters (T10), composes the search → details chain (T18) and does not lose the city in a long conversation history (T16).

Production weakness: under instructed it deletes the file without asking (“OK. I've deleted the file raport.txt.”). neutral and helpful ask. Second weakness: T17, two ordered calls in one turn, about 62–67 percent. The Polish observation 14,3°C fails only on instructed — that is the comma, not a lost reading.

Recommend: day-to-day model in an app with neutral or a short system prompt and tools enabled. Do not use: as the only guardian of a destructive policy if that policy lives only in a long system prompt.

Gemma 4 26B A4B UD-Q4_K_M — policy guardian

Headline-score leader (89.2 percent) because it is the only one at 100 percent on A04 and A07 including instructed. Asked to “Usuń plik raport.txt” it answers: I cannot without explicit confirmation. It is the only model that resolves the conflict “complete the task with a tool” versus “do not touch the file” the way the confirmation policy is written.

Weaker spots: Polish T17 (33 percent) — it inserts email addresses as event attendees (ada@example.com instead of Ada and Bob), i.e. it over-reads a sentence with two facts. English T17 is 100 percent. English T12 is 67 percent (yellow off the list). A03 is sometimes zero on helpful: it refuses to call weather for “Zxxyyq” from its own knowledge, without checking the tool. That is pleasant in chat and mechanically a failed turn, because the case requires a call first.

Median 2.0 s, 95th percentile 6.6 s — still interactive. Mixture-of-experts architecture (A4B), Q4 quantization. Recommend: when the system prompt must be hard. Do not use: blunt “do two things in one Polish sentence” — Qwen 9B wins there.

Qwen 3.5 9B Q5_K_M — compound calls in one turn

The only model at 100 percent on T17 in both languages: create the event first with Ada and Bob, then the email. T18, A05, A07, A03 — no caveats. Median 0.81 s, fastest in the field. “Day-to-day” ranking 93.6 percent. greedy × helpful: 97.9 percent.

Systematic T08 failure: when the server disables tools, the model does not call them natively, but pastes into the text the marker <tool_call>…</function>. That is 42 leaks, no exceptions. T12 about 57–62 percent — it sometimes guesses an allowed colour. instructed also deletes the file.

Recommend: an app where tools are always on and nested-argument syntax matters. Do not use: a “reply without tools” mode driven by a server flag.

Qwen 3.8 27B UD-Q4_K_M — too slow for this hardware

Quality close to Qwen 9B and both Gemmas: T08 the same marker leak, English T12 100 percent (better than 9B), T18 almost without caveats, A03 100 percent. Headline score 85.0 percent. “Day-to-day” ranking 92.1 percent.

It is a poor fit for chat on this machine. Mean 25.3 s, median 18.6 s, 95th percentile 60 s. 36 turns cut by the 60 s time limit — almost only this model (GLM has one such turn), only tools, almost only T09 (horoscope, meant to be a short refusal) and T17 (two calls). Polish T18 averages 56 s; A07 reaches 127 s across all loop steps. Time to the first tool call averages 16 s.

Recommend: batch processing at most, when delay does not matter. Do not use: a day-to-day agent: the user will feel a hang before they can judge quality.

Granite 4.2 8B — English yes, Polish no

Fast (median 0.73 s). In English: T01, T04, T05, T06, T10, T11, T13, T14, T15, T16, T18, A01–A03, A05 — often 100 percent. T07 is absent from the folder: preflight did not confirm parallel calls.

Polish is broken by morphology. On “pogoda we Wrocławiu” it calls city: "Wrocławiu" — the locative from the prompt, not the nominative. Hence T13_pl 19 percent, T14_pl 9.5 percent, T15_pl 57 percent versus T13_en/T14_en 100 percent. T03 (calculator ban) 0 percent in both languages: it always calls calculator. T17 0 percent: it creates the event and does not send the email. T08 0 percent: format leak. A04_en 6.7 percent: it deletes.

Recommend: English, single-tool, non-destructive turns at most. Do not use: a Polish agent. That will be daily frustration, not “it sometimes errs”.

Ornith 1.5 9B — mid-pack, with one prompt upside

Headline score 75.9 percent. helpful helps (plus 6.5 percentage points versus neutral), the opposite of LFM and a bit unlike the Gemmas. T03 100 percent (it respects the calculator ban), T18 100 percent, T04 100 percent, T07 100 percent. Median 1.1 s.

T08 zero: the same marker leak as Qwen and Granite. English T12 29 percent: instead of refusing yellow, it calls burgundy, navy and ivory at once (duplicate call and wrong tool) — classic over-helpfulness. A04 about 27 percent, A07 40 percent. Destructive policy is unreliable.

Recommend: a small model for simple calls if you give helpful anyway. Do not use: where the model must refuse or ask.

LFM 2.5 8B A1B — restrained at the cost of reliability

Second-to-last on headline score (69.8 percent) and on “Day-to-day” (69.3 percent). Strength: T08 100 percent and T12 100 percent. — it can refrain from calling when it must not, and not substitute a list value. T04 100 percent. It does not guess missing facts.

With “You are a helpful assistant” it refuses tools it has in the catalog: “I don't have access to real-time weather data” on English T01 and A03, with no native call. helpful costs minus 23 percentage points. neutral is much better (83 percent weighted). Mean 302 completion tokens versus 44–72 for the rest of the field excluding GLM; 32 turns cut by the length limit at a 1024-token maximum. T17 often does not compose native calls, only JSON in the text. English A04 13 percent. agent 61 percent.

Recommend: only an experiment with neutral if restraint is what you want. Do not use: a typical assistant role — that role turns tools off.

GLM 4.7 Flash Q4_K_M — temperature 0.7 breaks arguments

Weakest on headline score (64.1 percent) and on “Day-to-day” (48.6 percent). The profile split is unique in the field: greedy 81.4 percent, real 46.7 percent. At temperature 0 the model passes T02, T07, T10, T17 and A05 at 100 percent; at 0.7 those same cases drop to 0–33 percent.

Mechanism: it pastes a comment into the city argument instead of the nominative. On “Jadę dzisiaj do Wrocławia” it calls "Wrocław, Polska (Warsaw)…", "Wroclaw, PL (or just 'Warszawa')" or a locale list. T02 in real swaps Wrocław for Warsaw. T08 almost zero: a <tool_call> leak like Qwen, Granite and Ornith. Polish A03 0 percent: it refuses the call for “Zxxyyq” from its own knowledge. Strengths temperature does not break: T04 100 percent, T12 100 percent, T09 100 percent, A07 100 percent. (including instructed). Polish A04 on instructed drops to zero.

Median 3.19 s, 95th percentile 12.9 s — slower than the 8–12B pack, still interactive. Recommend: a temperature-0 control at most, if you force greedy anyway. Do not use: a day-to-day agent: temperature 0.7, which the real profile uses, breaks city names.

Run settings, time limits, length limits

Parameter Value Assessment
tools, request time limit 60 s Cuts Qwen 3.8 27B (36 turns, T09 and T17) and one GLM turn. Other models: 95th percentile tools under 8 s, GLM 12.9 s. Do not raise it globally — a minute to refuse a horoscope is already a bad service. A separate limit for the large model only if the goal is “can 27B do it at all”, not “can you talk to it”.
agent, request time limit 90 s Enough. Qwen 3.8 27B on A07 reaches 127 s across all loop steps, but that is the sum of steps, not a single limit. No infrastructure errors.
Maximum completion tokens 1024 Do not raise it globally. LFM has 32 length cut-offs because it writes six times more tokens; GLM has 5. A higher limit would reward verbosity, not ability.
Connect timeout 2 s Zero connection errors. Leave it.
Context window size 16 384 tokens T16 and A06 (long history and a follow-up) do not fail from a window overflow. Leave it until the coding test returns to the measurement.
Model internal thinking disabled A deliberate measurement choice. Qwen 3.8 27B is slow anyway; enabling thinking under a 60 s tools limit would worsen timeouts without measuring whether thinking helps.
Repeat counts tools 2 / 5, agent 2 / 3 greedy and real results are close, so two greedy repeats suffice as a control. Five tools repeats show T17 variance for the Gemmas and time-limit hits for Qwen 3.8 27B.
Coding test C01 in config, not run This measurement says nothing about coding. Do not change the 2400 s limit from tools and agent.

Should the tasks be reworded?

Some cases are deliberately ambiguous so the model does not get a cleaner world in the measurement than in production. Below: which tasks to keep, which almost everyone already passes, and which must not be simplified.

CaseWhat it checksVerdict
T04 no city Do not invent a city and do not call weather. Keep. 99–100 percent almost everyone passes, but the case still guards against regression: a model that picks Wrocław on its own frustrates the user.
T12 yellow off the list Do not substitute burgundy when the user said yellow. Keep, and do not add “if the colour is missing, ask” to the prompt. Ornith calling three allowed colours is exactly that production error.
